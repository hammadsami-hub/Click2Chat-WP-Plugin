# Click2Chat – WP Plugin

A lightweight and customizable WordPress WhatsApp button plugin with multiple designs, customizable colors, flexible positioning, and responsive settings for mobile, tablet, and desktop.

## ✨ Features

- 5 different WhatsApp button designs
- Customizable colors and appearance
- Flexible button positioning
- Responsive settings for mobile, tablet, and desktop
- Custom WhatsApp number and pre-filled messages
- Easy-to-use settings and customization options
- Compatible with popular WordPress themes and Elementor

## 📦 Installation

1. Download the plugin ZIP file from this repository.
2. Activate Click2Chat and configure your settings.

## 🚀 Download & Try

Download the plugin ZIP file from this repository, install it on your WordPress website, and explore its customization options.
